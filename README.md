# CS50's Introduction to Programming with Python — Practice Exercises

Solutions and practice exercises completed while studying Python fundamentals. This repository is a learning archive rather than a production application.

## Topics covered

- **Strings and input:** `indoor/`, `playback/`, `faces/`, `camel/`
- **Conditionals:** `deep/`, `bank/`, `extensions/`, `interpreter/`, `meal/`
- **Loops and validation:** `coke/`, `fuel/`, `grocery/`, `nutrition/`, `plates/`, `taqueria/`, `twttr/`
- **Libraries and formatting:** `emojize/`, `figlet/`
- **Dates and conversions:** `outdated/`, `einstein/`, `tip/`

Each exercise is stored in a separate folder with a Python script.

## Running an exercise

Use a recent Python 3 installation. For example:

```bash
git clone https://github.com/CaioYgor28/CS50-Python.git
cd CS50-Python
python bank/bank.py
```

Some exercises import optional third-party packages. Install the package requested by the exercise if Python reports a missing dependency.

## Why I keep this repository

I use these small programs to practice the fundamentals of readable Python: conditionals, iteration, functions, input validation, and problem decomposition.

**Course:** [CS50's Introduction to Programming with Python](https://cs50.harvard.edu/python/). This is an independent collection of exercise solutions, not an official course repository or certificate of completion.
